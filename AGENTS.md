## Project Overview

Karam is a Next.js 15 (App Router) marketing + CMS website for a creative agency, with:
- Multi-locale (ar / en) public site
- Admin dashboard for content, sections, media, settings, inquiries
- Supabase (Postgres + Storage + Auth + RLS)
- React Three Fiber 3D world backgrounds
- Neon editor / montage UI (intro clapper, timeline dock)
